# 四柱双引擎对拍校验 · BaZi Verify

> 八字排盘最常出错的地方不是算不出来，是算出来你不确定对不对。这个工具用两个互不依赖的实现算同一张盘，对不上就报警。

---

## 这是什么

一个四柱（八字）排盘与校验工具。

它同时调用两个彼此独立的干支计算实现，算出同一张盘的年柱、月柱、日柱、时柱，然后比对。两边一致才放行，不一致就返回冲突详情，由人裁决。

## 为什么需要

排盘错一天，后面全错。

命理分析、命盘可视化、命运K线这类产品，只要四柱错一格，整条结论链作废。而干支计算有几个经典陷阱：

- **节气交接**：月柱按节气分界，不是按农历月份
- **子时归属**：早子时 / 晚子时算哪一天，各家口径不同
- **换日点**：不同实现有的按 23:00 换日，有的按 00:00
- **真太阳时**：是否按出生地经度校正

单引擎跑出来的结果，你没法知道它踩没踩这些坑。双引擎对拍能暴露分歧。

## 用法

```bash
python bazi_verify.py --solar 1990-05-15 --hour 12:00 --sex 男
```

返回五值判定之一，附四柱原始值与分歧点。

两个引擎：
- `pai_pan.py`：本机自实现，纯标准库，太阳视黄经定气 + 定朔
- `lunar_python`：第三方历法库（6tail/lunar-python，MIT）

安装依赖：

```bash
pip install lunar_python
```

| 判定 | 含义 |
|---|---|
| `pass` | 两引擎结果一致 |
| `fail` | 存在冲突 |
| `in_doubt` | 边界情况（如节气交接点） |
| `unknown` | 输入不足 |
| `not_observed` | 未执行 |

## 设计原则

- **不许凭空写四柱**：任何对外输出的四柱，必须先跑一次校验
- **冲突不自行选边**：两版对不上时标 `mismatch` 摆出来，不擅自挑一个
- **边界情况显式标记**：节气交界、子时、真太阳时这类，判定降级为 `in_doubt`

## 适用范围

**能算**：年柱、月柱、日柱、时柱，大运起运。

**不处理**：择日、紫微斗数、六爻——这些是别的体系，别混用。
